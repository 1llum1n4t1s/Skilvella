# クライアント探索先のリンクと検出表示

[client-sync.md](client-sync.md) から分割した詳細です。

## 探索先へのリンク

Claude Code・GitHub Copilot（CLIは `~/.copilot/skills/<name>/SKILL.md` だけを探索）・Devin（探索の深さが未確認）は、生成物の一括公開を他と同じ所有フォルダーで行い、探索先（`~/.claude/skills`・`~/.copilot/skills`・`<Devinの設定フォルダー>/skills`）にはスキルごとのリンクだけを置きます。WindowsはFSCTL_SET_REPARSE_POINTで作るジャンクション（権限不要）、macOS・Linuxはシンボリックリンクです。

- 作成・引き継いだリンクはクライアントごとの `<所有記録>/links.json`（Claude Codeは旧版と同じ `claude-index/links.json`）に置き場・リンク先・名前で記録し、置き場の末尾とリンク先が記録と一致するものだけを外します。
- 利用者のフォルダーや別の場所へのリンクは上書きせず、名前を同期エラーに表示します。
- 旧版の手動移行で張られた、同名のCodex入口（`~/.agents/skills/skilvella/<name>`）へのリンクは、Claude Codeに限り生成物しか指さないものとして張り替えて引き継ぎます。
- 置き場が変わったときに旧リンクを外せなければ、旧記録を保って新しいリンクを作りません。リンク置き場が管理フォルダーと重なる場合は同期しません。
- Cursorはリンクを辿らない既知の不具合があるため、Grokと同じ実ファイル配置です。

## 設定画面の検出表示

設定画面は、このPCで各クライアントの設定フォルダー（Codexは `~/.agents`・`~/.codex`・`CODEX_HOME`、他は `~/.claude`・`~/.grok`・`~/.cursor`・`~/.copilot`・Devinの設定フォルダー）が見つかったかを `Library::detected_clients` で判定し、見つからないクライアントの同期先を同じフォーム内の折りたたみへ入れます。

有効・生成済み・同期エラーありのクライアントは検出の有無にかかわらず折りたたみません。フォームは `targets=true` で未送信のクライアントを無効化するため、隠すと保存時に黙って無効化されるからです。状態の表は有効またはエラーありのクライアントだけを並べます。判定は表示だけに使い、同期の可否には使いません。
