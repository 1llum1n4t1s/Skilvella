# 採用した構成の理由とトレードオフ

[DESIGN.md](../../DESIGN.md) から分割した詳細です。

- 固定3ツールで「検索→本文→参照」の順に必要な情報だけ渡し、スキル数に伴うツール定義の増加を避けます。キーワード検索なので、言語をまたぐ意味検索は行いません。将来意味検索を追加する場合も、ツール数を増やさず検索サービス内に追加します。
- ファイルを正本とすることで外部エディターと併用できます。その代わりに監視・再スキャン・ハッシュによる競合検出が必要となり、ファイルとDBの完全な原子性は持ちません。
- 単一実行ファイルとSSR・同梱アセットにより、ローカル配布と実行環境を簡素にしています。PNGとICOの生成は独立した開発用パッケージ `tools/export-icons` が担い、通常ビルドは追跡済みのアイコン素材を使用します。
- 監視通知を約450 msまとめてから走査し、連続変更による走査を抑えます。即時反映は保証せず、監視エラーやオフラインからの復帰には手動再スキャンも残しています。
