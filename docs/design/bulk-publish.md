# 一括公開と公開状態の更新

[data-flow.md](data-flow.md) から分割した詳細です。

取得元ごとの一括設定は `/repositories/bulk` から `AppState::run_mut` を通し、選択した取得元を操作ロック内で分類・検証します。

- 対象はPOST時点の全スキルで、一覧のページ上限を適用しません。不在・エラーの索引行は対象外件数へ数えます。
- 重複する選択は一度だけ扱い、未知の取得元は拒否します。
- 公開時は各ファイルを再検証し、全対象の公開状態・Codexポリシーを一つのDBトランザクションで保存します。一件でも検証に失敗すれば全件を取り消し、保存後は通常のCodex同期を待ちます。
- 原本・タグ・カテゴリ・履歴は維持し、取得元の既定値や今後追加分への継承は作りません。

一覧の「状態」列のラジオボタンは `/skills/{id}/published` から `Library::set_published` を呼び、公開状態だけを `AppState::run_mut` 内で保存します。公開時は `set_metadata` と同じくファイルを再検証し、不在・読み取りエラー・不正frontmatterは公開せず、画面のJavaScript（`Accept: application/json`）には選択を戻すためのエラーを返します。タグ・カテゴリは上書きしません。
