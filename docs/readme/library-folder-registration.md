# Registering and managing folders

Part of [Managing your library](library-management.md).

## Automatic detection on first launch

Skilvella checks `~/.agents/skills`, `$CODEX_HOME/skills`, and `~/.codex/skills` in that order. If none exists, it creates `<data-folder-name>-skills` next to the data folder. If sources were registered before, that configuration takes priority and is carried over.

A candidate that contains only Codex invocation entries generated by Skilvella is skipped, and those entries are not counted as managed skills. This holds only while the data folder has an ownership record for them. If you recreate the data folder or point to another one with `--data-dir`, leftover generated entries are registered as ordinary skills.

If a problem reading the ownership record or the candidates prevents detection from being finalized, the saved automatic registration target is kept. Check the detection status in the folder list on the left.

## Adding a folder

The library is one screen: managed folders on the left, skills on the right. Press "+ Add folder" to open the OS folder picker. The chosen folder is registered as is and scanned; files are not moved. No name is needed, because the folder name becomes the display name (change it later with "Change display name"). Where the dialog cannot open (such as SSH sessions), enter an absolute path under "Enter a path instead".

If the folder is already managed, or has a parent/child relationship with a managed folder, the addition is stopped and the overlapping folder's name is shown.

## Managing a folder

Selecting a folder shows its location, skill count, and standard-discovery-path warning, plus "Change display name" and "Stop managing". "Stop managing" never deletes files. For the default folder, "Change referenced folder" (or "Browse…") switches the referenced folder, and the setting persists across restarts.

## Moved or deleted folders

If a folder is moved or deleted outside Skilvella, a warning appears in the sidebar and on the folder's page, and sync stops until it is resolved.

- If you moved it, open "Change folder location" and enter the new location (or choose with "Browse…"). Only the registration is updated: files are not moved, and skill IDs, publication state, usage settings, and history are kept.
- If you no longer need it, choose "Stop managing".
- If the new location is already managed as another folder, stop managing that folder first.
