# 管理フォルダー・Library・MCPのテスト

- `tests/relocate.rs` は、フォルダーの移動後に同期が停止しても画面が開き「管理から外す」で復旧すること、場所の付け替え（識別子・公開状態・使い方・履歴の保持、同期の復旧、別の有効なフォルダーとの重複・親子・存在しない場所・データフォルダーとの重なりの拒否、既定フォルダーの設定の更新、CSRF）と、読み取れないフォルダーの警告・同期停止の警告からのリンク・場所の変更フォームの形（`data-save-on-change` を付けない明示送信）を検証します。
- `tests/library.rs` は保存・検索・パス境界、`tests/directory.rs` は管理フォルダーの選択、フォルダー追加時の識別子の自動採番・同じフォルダーの再登録・重複と親子関係の拒否、親子スキルの境界、`tests/http_mcp.rs` は管理フォームとMCPの連携・分割取得・継続時の競合検出、旧フォルダー画面の転送とフォルダー選択ダイアログのCSRF境界、一覧の公開切替（公開状態だけの保存と不正ファイルの公開拒否）、`tests/watch.rs` は外部変更の反映と付け替え後の監視先の張り替え、`tests/startup.rs` はヘッドレス起動とポート競合時の非変更、`tests/windows_icon.rs` はWindows版の本体に埋め込んだアイコンをシェルが取り出せること、`tests/migration.rs` は旧版の中断移行の起動時復旧・同一性検査・操作ロックを検証します。
- 変更した契約に対応する検証を維持してください。
- `tests/repositories.rs` は取得元の分類・件数・ページ分割・切断時の保持、不在登録削除のHTTP/CSRF境界と全件検証、読み取りエラーの修正経路を検証します。
- 管理画面の設定フォームは [settings-form.md](settings-form.md) の形を検証するテストも対象です。
